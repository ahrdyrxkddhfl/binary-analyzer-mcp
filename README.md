# Binary Analyzer MCP Server

의심스러운 바이너리 코드 또는 함수 정보를 분석하여
취약점 가능성과 보안 기법에 따른 공격 난이도를 설명해주는
MCP(Model Context Protocol) 기반 바이너리 분석 서버입니다.

## 프로젝트 목적

이 서버는 LLM과 연동되는 MCP 도구를 통해
다음과 같은 취약점 분석 흐름을 자동화하는 것을 목표로 합니다.

함수 목록 분석 → 위험 함수 취약점 검사 → 보호 기법 기반 공격 난이도 설명


## 제공 기능 (MCP Tools)
### analyze_symbol
바이너리에서 사용된 함수 목록을 분석하여
위험 가능성이 있는 주요 함수를 식별합니다.

### check_risky
C 코드 또는 pseudo-code에서
버퍼 오버플로우 위험 함수 사용 여부를 검사합니다.

### mitigation
바이너리에 적용된 보안 기법을 기반으로
공격 난이도와 관련 이론을 설명합니다.
(로컬 LLM: Ollama 사용)
